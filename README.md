# Project Work Marco Compagnoni. 

**Istruzioni:**

1. E' necessario aver installato Docker Desktop (https://www.docker.com/products/docker-desktop/)
1. Copiare il progetto in una cartella a piacere del proprio computer
2. Da terminale, posizionarsi nella cartella principale del progetto (Dove presente il file docker-compose.yml)
3. Lanciare il comando:

```bash
docker-compose up --build
```

4. Una volta completato il processo, per accedere:
   - Frontend: [http://localhost:3000](http://localhost:3000)
   - Backend: [http://localhost:5000](http://localhost:5000)
